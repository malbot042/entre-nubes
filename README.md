# Entre Nubes ✈

Simulador de vuelo 3D para el navegador (JavaScript + Three.js por CDN, sin Node ni compilación).
Jugable directamente desde GitHub Pages: abre `index.html` servido por HTTP.

- 15 aeronaves: Cessna 172, Extra 330, Learjet 45, Boeing 737, Spitfire, P-51, F-14 (ala variable), F-16, F/A-18, F-22, MiG-29, MiG-21, AH-64 Apache, Bell 206, Sikorsky S-76.
- Vista de cabina con interior detallado e instrumentos animados (analógicos, cristal, HUD) y giro de cabeza con el ratón; vista exterior y de pasada.
- Mundo procedural infinito: montañas, lagos, campos de cultivo, bosques, carreteras, ciudades, pueblos, granjas y parques eólicos.
- Aeropuerto de origen y destino aleatorios en cada vuelo (pista, luces, PAPI, terminal, torre).
- Día/noche, despejado, nuboso, cubierto, lluvia, tormenta con rayos, niebla y nieve.
- Audio sintetizado (motores, rotor, viento, lluvia, truenos, avisos).

Prueba local: `python3 -m http.server` y abre http://localhost:8000
Controles: tecla **H** dentro del juego.
